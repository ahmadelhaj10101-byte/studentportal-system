# Student Portal - نظام بوابة الطلاب

نظام شامل لإدارة المعلومات الأكاديمية للطلاب مبني باستخدام ReactJS و Tailwind CSS.

## 📋 الوصف

Student Portal هو تطبيق ويب متكامل مصمم لإدارة وعرض المعلومات الأكاديمية للطلاب. يوفر النظام واجهة سهلة الاستخدام تمكن المستخدمين من عرض بيانات الطلاب، المواد الدراسية، والدرجات بطريقة منظمة وجذابة.

## ✨ المميزات

- **واجهة مستخدم حديثة**: تصميم عصري وجذاب باستخدام Tailwind CSS
- **متجاوب بالكامل**: يعمل بشكل مثالي على جميع الأجهزة (سطح المكتب، التابلت، الهاتف)
- **صفحات متعددة**: 
  - الصفحة الرئيسية مع بانر وطلاب مميزين
  - صفحة من نحن (الوصف، الرسالة، الرؤية)
  - صفحة الخدمات (عرض الطلاب، المواد، الدرجات)
  - صفحة الاتصال (نموذج اتصال ومعلومات الحرم الجامعي)
  - صفحة الملف الشخصي للطالب (ديناميكية باستخدام React Router)
- **بيانات وهمية**: بيانات تجريبية مخزنة محلياً بدون الحاجة لخادم
- **تعليقات عربية**: جميع المكونات والدوال موثقة بالعربية
- **تنقل سلس**: استخدام React Router للتنقل بين الصفحات

## 🛠️ التقنيات المستخدمة

- **ReactJS 18**: مكتبة JavaScript لبناء واجهات المستخدم
- **Vite**: أداة بناء سريعة وحديثة
- **React Router DOM**: لإدارة التوجيه والتنقل
- **Tailwind CSS**: إطار عمل CSS للتصميم السريع
- **PostCSS & Autoprefixer**: لمعالجة CSS

## 🚀 التثبيت والإعداد

### المتطلبات الأساسية

- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع** (أو فك الضغط إذا كان مضغوطاً)

2. **تثبيت المكتبات المطلوبة**:
   ```bash
   npm install
   ```

3. **تشغيل المشروع في وضع التطوير**:
   ```bash
   npm run dev
   ```

4. **فتح المتصفح**:
   افتح المتصفح وانتقل إلى `http://localhost:5173`

### بناء المشروع للإنتاج

```bash
npm run build
```

سيتم إنشاء مجلد `dist` يحتوي على الملفات المُحسّنة جاهزة للنشر.

### معاينة الإنتاج

```bash
npm run preview
```

## 🎯 الاستخدام

### التنقل بين الصفحات

- استخدم شريط التنقل العلوي للانتقال بين الصفحات المختلفة
- على الأجهزة المحمولة، اضغط على أيقونة القائمة لفتح قائمة التنقل

### عرض بيانات الطلاب

1. انتقل إلى صفحة "الخدمات"
2. اختر تبويب "عرض الطلاب"
3. اضغط على "عرض الملف الشخصي" لأي طالب لرؤية تفاصيله الكاملة

### عرض المواد والدرجات

1. في صفحة "الخدمات"، اختر تبويب "عرض المواد" أو "عرض الدرجات"
2. استعرض المعلومات المطلوبة
